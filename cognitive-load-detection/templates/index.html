Project Defense

10 Viva Voce Defense Questions & Answers

Authoritative responses for project review committee and external examiners.

1. What is cognitive load, and how do typing patterns reflect it? ▼

Cognitive load is the total working memory resources utilized during task performance. When cognitive load increases, fine motor coordination experiences micro-hesitations, resulting in longer key hold durations, extended inter-key flight delays, frequent planning pauses (>1.5s), and increased backspace error corrections.

2. What is the difference between Key Hold Time and Flight Interval? ▼

Key Hold Time is the duration (in milliseconds) a physical key stays pressed down between keydown and keyup. Flight Interval (Inter-key Interval) is the latency between pressing one key and pressing the subsequent key, reflecting cognitive transition delay.

3. How did you prevent data leakage in your ML pipeline? ▼

Data leakage was strictly prevented by utilizing Scikit-Learn's Pipeline([('scaler', StandardScaler()), ('classifier', estimator)]). The StandardScaler is fitted exclusively on training folds during 5-Fold Stratified Cross-Validation without ever seeing holdout test data.

4. What models were evaluated, and how was the best model chosen? ▼

We benchmarked Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting. Logistic Regression and Random Forest both achieved top validation scores (F1: 1.000). Logistic Regression was saved as the primary winning pipeline for its superior inference speed and low memory footprint.

5. What are the top 4 most influential features according to Random Forest? ▼

Typing Speed (WPM), Average Inter-Key Flight Interval, Hesitation Pause Count (>1.5s), and Backspace Count were the top drivers distinguishing LOW, MEDIUM, and HIGH cognitive load classes.

6. How does your system protect user privacy? ▼

The platform processes timing biometrics only. Keystrokes are converted to numerical timestamps, hold times, and delay deltas. The typed text is never stored in files, databases, or logs.

7. Why is synthetic data used, and what is its limitation? ▼

Real cognitive load datasets require ethical review board (IRB) approval and medical monitoring hardware (EEG/eye-trackers). Synthetic data allows developing and validating the end-to-end data science architecture, but real-world clinical claims require experimentally validated human datasets.

8. How does the system calculate error rate? ▼

Using the dynamic programming Levenshtein Distance algorithm, which measures the minimum number of single-character edits (insertions, deletions, substitutions) required to transform the typed string into the target passage.

9. Is this system a medical diagnostic tool? ▼

No. The system estimates behavioral typing patterns for educational interfaces and adaptive software ergonomics. It does NOT diagnose ADHD, depression, anxiety, or medical neurological conditions.

10. What are future extensions of this project? ▼

1) Individual baseline calibration over multiple days; 2) Multimodal fusion integrating mouse movement acceleration and jitter; 3) Adaptive UX that dynamically simplifies interface forms when high cognitive load is detected.
